# Tarefas do front do cliente

Esta pasta guarda as telas usadas pelo cliente, que acessa pelo QR code da mesa.

## Telas previstas

- Cardápio com pratos, ingredientes, alérgenos e indicação de prato esgotado.
- Montagem do pedido, com escolha de ingredientes que podem ser retirados.
- Acompanhamento do pedido, mostrando em que etapa ele está.
- Pedido de conta, que avisa o garçom.
- Reporte de problema, com uma descrição simples.

## Arquivos previstos

- Página inicial do cliente, aberta pelo QR code da mesa.
- Arquivos de tela para cardápio, pedido, acompanhamento, conta e reporte de problema.
- Arquivos de estilo usados apenas nestas telas.

## Observações

- Os nomes dos campos devem ser iguais aos do contrato JSON.
- Nenhum cálculo de valor deve ser feito na tela; o front apenas mostra o que o back enviar.
- Enquanto o back não estiver pronto, usar os dados de mentira da pasta mock.
