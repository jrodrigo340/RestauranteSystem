# Tarefas do front comum

Esta pasta guarda o que é compartilhado por todas as áreas do front.

## Arquivos previstos

- config.js, arquivo único onde ficará o endereço do back. Ainda precisa ser criado.
- Arquivos de funções auxiliares para chamadas ao back.
- Arquivos de controle do token de login.
- Arquivos de estilo gerais e componentes visuais reaproveitados.
- Arquivos de formatação de data, hora e valores recebidos prontos do back.

## Observações

- O endereço do back deve existir em um único lugar, para facilitar a troca entre dados falsos e back real.
- Os nomes dos campos devem ser iguais aos do contrato JSON.
- Nenhum cálculo de valor deve ser feito na tela.
- A integração real com o back ainda precisa de liberação de CORS no back; isso é uma pendência.
