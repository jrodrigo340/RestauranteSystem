# Tarefas do front mock

Esta pasta guarda os dados de mentira usados enquanto o back-end não está pronto.

## Arquivos previstos

- Arquivos com listas falsas de restaurante, funcionários, mesas e sessões.
- Arquivos com cardápio, pratos, ingredientes e alérgenos falsos.
- Arquivos com pedidos, comandas, contas e pagamentos falsos.
- Arquivos com estoque, relatórios e reportes de problema falsos.
- Arquivos com avisos falsos para os painéis do garçom e da cozinha.

## Observações

- Os dados falsos devem seguir os mesmos nomes de campos do contrato JSON.
- Nenhum cálculo de valor deve ser feito na tela; os valores falsos já devem vir prontos.
- Quando o back estiver pronto, esta pasta deixa de ser usada, mas pode continuar existindo para testes.
